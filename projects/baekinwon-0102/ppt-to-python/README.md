# PPT to Python

새 프레젠테이션 생성 전용 런타임입니다. PPT Master의 SVG 작성·검증·변환 파이프라인과 `python-pptx`를 사용해 편집 가능한 PPTX를 만듭니다.

이 디렉터리는 통합 서버 구동에 필요한 `skills/ppt-master/`와 의존성 정보만 유지한 축소본입니다. 직접 실행하기보다 `ppt-unified-mcp`의 `ppt_generate_*` 도구를 통해 사용합니다.
