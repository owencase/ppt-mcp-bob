# PPT to COM

기존 프레젠테이션 수정 전용 런타임입니다. 실행 중인 Microsoft PowerPoint를 COM으로 제어해 슬라이드, 도형, 텍스트, 표, 차트, 미디어와 애니메이션 등을 읽고 수정합니다.

이 디렉터리는 통합 서버 구동에 필요한 `src/`와 패키지 정보만 유지한 축소본입니다. Windows와 Microsoft PowerPoint가 필요하며, `ppt-unified-mcp`의 `edit` 모드에서 사용합니다.
